## 1. テストの概要と目的
### 1.1 目的
本仕様は、ColorBeaconTimer が SW105 版数 4.5 の全要求（REQ-001 から REQ-007）と検証条件を満たすか検証する総合テスト計画である。Phase 2 では第1章から第4章までを策定し、第5章および第6章のテスト実行結果と総合判定は Phase 4 で AI が実行後に記入する。テストの自動・手動を問わず、実行者はすべて AI とする。

本ソフトウェアは、DADA（Document-and-Agent-Driven Agile）プロセスを用いたプログラム開発例であり、教育用途の公開物ではない（非教育用途）。本開発では、DADAプロセスの次の 2つの特徴を発揮している。(1) 開発文書（`SW105`・`SWP6`・`SW205`）を作成し、工程別レビュー記録表（`REV101_Requirements.md`・`REV101_Test.md`・`REV101_Design.md`・`REV101_Code.md`）と機械チェックで自己校正レビューを行っている。(2) Phase 5 の評価を起点とした開発 Loop により、アジャイル的にプログラムの要求改訂を頻繁に行っている。

## 2. テスト環境とシステム構成

### 2.1 システム構成
利用者の PC 上の Google Chrome に ColorBeaconTimer を拡張機能として導入し、chrome.windows で開く専用ウィンドウ上で表示と操作を行う。Windows 11 上の Chrome ポップアップウィンドウ実表示領域において、起動時の専用ウィンドウにおける実ビューポート幅は 640px 以上とする。全画面の表示要素は互いに重ならず、見切れおよび水平・垂直スクロールバーなしで収める。言語切替ボタンは設けず、表示する各日本語に英語を常時併記する。オープニング第2シーンの『ジムノペディ第1番』ループ再生と第3シーンのオリジナル・宇宙冒険SF映画風シンセサイザー楽曲シームレスループ再生は、PC の音声出力でオフライン再生する。第3シーンの楽曲再生では、第2シーン『ジムノペディ第1番』と同等水準の音量（再生時実効音量差が ±3.0 dB 以内）とする。残時間 0 ではピコン音のあとに、単一の元気な成人男性話者による一括合成音声で「ジュワッチ」を 1秒間かけて発音する。続いて既存画面表示を消去し、中央から 360度放射状にドットが飛散する終了演出画面と EXITボタン（ラベル「EXIT」）を表示する。EXITボタン押下または専用ウィンドウを閉じる操作により、プログラムを終了する。BGM、ピコン音、およびジュワッチ音声の再生では外部サーバと通信しない。

## 3. テスト方針
### 3.1 合否判定基準
第4章に定義したすべてのテスト項目（実行区分「自動」および「手動」の合計 77件：自動 64件・手動 13件）について、AI が実行した結果がすべて Pass である場合に限り、総合判定を Pass とする。1件でも Fail が存在する場合は、総合判定を Fail とする。合格条件に用いる数値および許容誤差は SW105（版数 4.5）に記載された値のみとし、SW105 にない独自の数値を追加しない。

### 3.2 異常系・例外テスト方針
REQ-001 から REQ-007 の各要求に対し、正常系を 1件以上、異常系または境界値テストを 1件以上配置する。境界値テストでは、許容誤差の境界上の値を合格、境界の外側の値を不合格とする。第3シーン BGM の音質検証では、サンプリング周波数 44.1kHz（44100Hz）以上・16bit・ステレオ・最大正規化振幅 0.30〜0.95 の境界値と境界外側を確認する。シームレスループ検証では、ループ境界無音ギャップ 0.05秒未満と末尾・先頭接続点の正規化振幅差 0.05 以下の境界値と境界外側を確認する。第2シーンと第3シーンの BGM 音量バランス検証では、再生時実効音量（全区間 RMS 基準の dBFS）差の絶対値 3.0 dB 以内と再生時クリッピング非発生の境界値と境界外側を確認する。REQ-005 のジュワッチ音声検証では、非圧縮 PCM WAV（24000Hz 以上・16bit・モノラル）形式を確認する。あわせて、総発音時間 0.80秒〜1.20秒・全体ピーク正規化振幅 0.85〜0.99（非クリッピング）・全区間 RMS 0.18 以上（-14.9 dBFS 以上）の境界値と境界外側を確認する。さらに、全体有声区間フレームの基本周波数（F0）中央値 110 Hz 以上 180 Hz 以下（女性声域 220 Hz 以上不使用）の境界値と境界外側を確認する。前半区間（先頭 65%）および後半区間（後半 35%）の各有声区間における F0 中央値では、85 Hz 以上 200 Hz 以下（声質断絶なし）の境界値と境界外側を確認する。後半区間（後半 35% 有音部）ピーク振幅では、前半区間（先頭 65%）ピーク振幅比 0.25 以上 0.85 以下の境界値と境界外側を確認する。後半 3kHz〜8kHz 高域帯域 RMS では、前半全帯域 RMS 以下の境界値と境界外側を確認する。専用ウィンドウと日英併記の検証では、起動時実ビューポート幅 640px 以上（640px 合格と 639px 不合格）を確認する。あわせて、言語切替ボタン非存在・全画面非重複・見切れと水平および垂直スクロールバー非発生を確認する。終了演出では、EXITボタン（ラベル「EXIT」）がドット飛散状態のみに表示され他状態では非表示であること、ならびに押下終了後の第1シーンからの再起動を確認する。配布文書の検証では、`manifest.json` の `description` 132文字以内（132文字合格と 133文字不合格の境界）、禁止名称、および禁止表現の非混入を確認する。さらに、DADAプロセス位置づけと 2つの特徴、旧教育用途禁止5語句の非混入、および `README.md` の「開発状況」節非存在・「機能概要」節簡素化を確認する。専用ウィンドウが途中で閉じられた場合は、再生中 BGM の停止とともにプログラムを終了する。再度開いたときは、前回の途中からではなくオープニング第1シーンから開始することを確認する。オープニング第2・第3シーンで BGM 音声ファイルの読み込み不能・デコード失敗・音声出力デバイス利用不可が発生しても、例外を送出せず無音フォールバックとする。無音フォールバック状態でも画面表示・ボタン遷移・設定画面遷移・タイマー動作が継続することを確認する。ボタン連続押下による短時間遷移でも旧シーン BGM が即座に停止し、重複再生が発生しないことを確認する。また、残時間 0 でジュワッチ音声を再生できない異常状態では、残時間 0 の時点でランプ消灯後に終了演出（REQ-007）へ遷移することを確認する。

### 3.3 AIが非スクリプトで実施する項目（実行区分「手動」）
スクリプトによる機械的検証が困難な視覚表現・聴覚表現の確認（実行区分「手動」）は、Product Owner ではなく AI が担当する。AI はブラウザ操作ツールおよび画面・音声観測手段を用いて確認し、期待される出力と照合して Pass または Fail を判定する。好みや使用感のような主観的検収は SWP6 に含めず、Phase 5 の検収へ残す。Product Owner（マサ）が公開前に確認する項目は、曲調や音量バランスの聴感適否、ならびに単一の元気な成人男性話者による「ジュワッチ」一括発音の聴感適否である。実ビューポート幅 640px 以上の外観（EXITボタン表示・終了動作含む）、配布文書の記載内容、および著作権・商標の最終判断も Phase 5 の検収事項であるため、SWP6 の合否判定対象には含めない。
