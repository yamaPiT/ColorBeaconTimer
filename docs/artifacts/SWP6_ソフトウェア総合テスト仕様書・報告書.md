## 3. テスト方針
### 3.1 合否判定基準
第4章の自動のテストと手動のテストが、すべて Pass のとき、総合判定を Pass とする。
1件でも Fail があれば、総合判定を Fail とする。
オープンクエスチョンの数値を、合格条件へ追加しない。
総合判定を記入するのは Phase 4 の AI である。
記入先は第6.2節である。
人間が第5章または第6章へ結果を書くことは、合格条件に含めない。
実行区分が手動のテストも、AI が実施して Pass または Fail を付ける。

### 3.2 異常系・例外テスト方針
各 REQ について、正常系を1件以上、異常系または境界を1件以上置く。
許容誤差の端の値は合格とする。
端の外側の計測は不合格とする。
端の外側の値を製品へ注入する手順は、SW105 に無い。
不合格の範囲は、各テストの期待される出力に書く。
専用ウィンドウを閉じたあとは、実行が終わり、開き直すとオープニングから始まることを確認する。
閉じる前の残時間の続きからは始まらない。
掛け声の音声ファイルを再生できない場合は、残時間 0 の到達後に終了演出へ進むことを確認する。
禁止名称リストの名称が混入したときの除去は、SW105 第7章の公開前確認である。
実行中の自動除去手順は SW105 に無い。
本仕様は、混入が 0件であることを合格条件にする。
出撃ボタンが円形で光ること、および出撃演出が公式の変身アイテムを真似ないことは、数値の判定基準が SW105 に無い。
ラベル「ジュワッチ！」と演出の順序はテストする。
円の比率、輝度、類似度は OQ-7 と OQ-10 に残す。

### 3.3 AIが非スクリプトで実施する項目（実行区分「手動」）
手動のテストは AI が実施する。
Product Owner が手動テストを実施する前提にはしない。
AI は、第2.1節の Chrome で専用ウィンドウを表示し、画面と音を観測する。
観測結果を、期待される出力の文字列または数値と照合して Pass または Fail を付ける。
好みと使用感は、本仕様に書かない。
Phase 5 の検収へ残す。

手動のテストは次のとおりである。

- TC-005、TC-010、TC-011、TC-012、TC-014。対象はオープニングの見た目と、マサの目視記録の読み取り
- TC-028（出撃演出の映像の順序）
- TC-029、TC-030、TC-035、TC-036。対象は色名と点滅の見た目
- TC-039、TC-041。対象は境界時刻の色名
- TC-045、TC-053（聴いた音と文字の照合）
- TC-052（同梱ファイルが公式素材でないこと）
- TC-057（NASA の記章とロゴの有無）
- TC-061（星の流れる方向と継続）

REQ-001 の写真トレースと筆跡の判定者は、SW105 の検証条件どおり Product Owner マサである。
AI は、マサの判定記録を読んで TC-012 を判定する。
記録の保管場所は OQ-1 である。
